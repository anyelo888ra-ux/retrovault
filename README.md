# 🕹️ RetroVault Arcade - c00lcompany

Plataforma web de juegos retro y emuladores clásicos (MS-DOS y Arcade) desarrollada por **c00lcompany** / **c00lkidd_v2yt**.

## 🚀 Características
- Emulación web de títulos clásicos como MS-DOS (Doom) y juegos arcade.
- Interfaz con diseño retro / CRT optimizada para navegadores modernos.
- Integración nativa con despliegue en Vercel.

## 📂 Estructura del Proyecto
- `index.html`: Menú y catálogo principal.
- `style.css`: Estilos visuales de la interfaz retro.
- `js/`: Scripts de control y librerías de emulación (JS-DOS).
- `games/`: Contenedores de assets y ROMs (Doom, Pacman, etc.).
